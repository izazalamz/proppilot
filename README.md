# 🚀 PropPilot - Multi-tenant Property Management System

PropPilot is a SaaS platform built for property owners, managers, and tenants.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js, Prisma ORM, PostgreSQL, JWT
- **Frontend:** React 19, Vite, Tailwind CSS, shadcn/ui

## 📂 Project Structure
- `backend/` - Express API & Prisma database models
- `frontend/` - React client app
